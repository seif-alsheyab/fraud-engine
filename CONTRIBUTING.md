# Contributing

**This repository does not accept contributions.**

It is published so that the author's engineering work can be read and
evaluated. It is not a collaborative project.

- Pull requests are closed and locked automatically.
- Issues are disabled.
- The `main` branch is protected and accepts commits only from the author,
  cryptographically signed.

You are welcome to read the code. See `LICENSE` for what you may do with it.
